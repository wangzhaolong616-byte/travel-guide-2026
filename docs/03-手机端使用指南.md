# 📖 03 · 手机端使用指南

宝典在手机/平板上有两种用法：**在线版**（始终最新）和**离线版**（单文件随拷随用）。推荐主力用在线版，出行没网时用离线版兜底。

---

## 1. 在线版：浏览器直接打开

1. 手机浏览器（推荐 Chrome / Edge / Safari）访问：
   **https://wangzhaolong616-byte.github.io/travel-guide-2026/**
2. 网站已做移动端适配：单列卡片、筛选横滑、弹窗自适应小屏，无横向滚动

### 添加到主屏幕（像 App 一样用）

宝典是标准 **PWA**：带专属图标、可独立窗口运行、**首次访问后支持离线打开**（Service Worker 缓存）。

- **iPhone（Safari）**：打开网址 → 底部分享按钮 ⬆️ →「添加到主屏幕」→ 确认。主屏幕出现宝典图标，点开全屏运行
- **Android（Chrome）**：打开网址 → 右上角 ⋮ →「安装应用/添加到主屏幕」→ 确认
- 已适配 iPhone 刘海屏/挖孔屏安全区（内容不会被刘海/手势条遮挡）；深色浅色**自动跟随系统**，也可手动切换
- 离线说明：第一次在线访问后，断网再打开仍可使用（HTML 与图标已缓存）；内容更新后联网打开一次即自动刷新

## 2. 离线版：把 HTML 传到手机

离线版就是仓库里的 `中国旅行宝典2026.html` 这一个文件（约 700KB），任选一种方式传到手机：

| 传法 | 步骤 |
|---|---|
| 💬 微信/QQ | 文件传输助手发给自己 → 手机端"用其他应用打开" → 选浏览器 |
| ☁️ 网盘/WPS | 电脑端放入云盘同步目录 → 手机装对应 App → 用浏览器打开文件 |
| 🔌 数据线 | 拷贝到手机"下载"目录 → 文件管理器点击 → 选浏览器打开 |
| 📧 邮件 | 发附件给自己 → 手机下载 → 浏览器打开 |

**⚠️ 关键提示：一定要用浏览器打开，不要用微信内置浏览器**（功能受限且不易保存）。文件下载后点开就能用，全程不需要网络。

## 3. 手机端的交互方式

- **看攻略**：点任意省份卡片进入，点城市名展开区县明细
- **收藏**：卡片右上角 ♥（点击区域已加大，不易误触）
- **足迹**：顶栏 🗺️ → 点省份瓦片点亮，成就自动解锁
- **出行清单**：详情页点 🧳，勾选项直接点
- **展开/收起**：详情页"⊕ 展开全部 / ⊖ 收起全部"
- **翻省**：详情页底部的 上一个/下一个 按钮
- **筛选**：地区/主题标签横向滑动选择
- **月历**：首页横滑查看 12 个月

## 4. 手机端数据说明

- 收藏、足迹、清单勾选保存在**手机浏览器本地**：添加到主屏幕的在线版与浏览器直接打开的数据互通（同一浏览器）；离线版的数据独立保存
- **清理浏览器数据会丢失收藏/足迹**，建议定期点"复制"把清单文字备份到备忘录
- 换新手机：用"复制旅行报告/复制清单"文字迁移即可

## 5. 省流量与加载技巧

- 单文件约 700KB，在线版每次打开都会重新加载；离线版零流量
- 弱网环境建议直接用离线版
- 离线版想升级？重新从仓库下载一次覆盖旧文件即可（收藏数据在浏览器里不受影响——仅限同一路径打开；离线版以本地文件方式打开，路径变了数据会重置，升级前先复制备份）
