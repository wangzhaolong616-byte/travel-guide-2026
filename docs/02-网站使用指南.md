# 📖 02 · 网站使用指南

本指南带你把《中国旅行宝典 2026》的每个功能用明白。在线版与离线版功能完全一致。

---

## 1. 首页总览

从上到下依次是：

1. **顶栏**：logo（点击回首页）、搜索框、🎲 随机、🗺️ 足迹、🌙 深色模式、❤️ 清单
2. **英雄区**：标题 + 数据统计（34 省 · 243 城 · 802 区县 · 4572 条目）
3. **出行月历**：12 个月的"这个月去哪"，**自动定位并高亮当前月**，点月份卡上的省份名直达该省攻略
4. **筛选区**：地区筛选（华北/东北/华东/华中/华南/西南/西北/港澳台）+ 主题筛选（美食/海滨/古镇/雪山/避暑…）+ 排序（综合推荐/按评级/按地理顺序）
5. **省份卡片墙**：每张卡片 = 一省的精华简介（未点开前看这里就够了）

## 2. 三级攻略：省 → 城市 → 区县/板块

- **点击任意省份卡片**进入详情页
- 详情页从上到下：概览（简介+最新动态）→ **城市与区县**（每个城市是一个可折叠卡片，首个默认展开）→ 省级美食榜 → 景点榜 → 特色体验/演出/夜生活 → 路线推荐 → 交通与预算 → 避坑指南+伴手礼
- 城市卡里再点开有 **区县/板块细分**（怎么玩/吃什么/觅食街区/住宿建议）
- 顶部胶囊导航（概览/城市/美食榜…）点击可平滑跳到对应板块
- 详情页底部有 **← 上一个地区 / 下一个地区 →**，像翻书一样逛完全国
- 页面左上角 `← 返回全部地区` 或浏览器返回键回到卡片墙，**滚动位置会精确恢复**

## 3. 搜索（支持拼音）

- 支持搜索：**省份名、城市名、区县名、菜名、景点名、简介关键词、拼音**（如 `sichuan`、`xizang`）
- 输入时卡片墙实时过滤，框内显示"N 个地区匹配"
- **回车**直达匹配度最高的省份详情
- 按 **`/`** 键随时聚焦搜索框，**Esc** 清空
- 提示：搜"火锅"能找出所有火锅强省，搜"银杏"能找出季节限定景点

## 4. ❤️ 想去清单

- 卡片右上角 **♥**、详情页 **♥ 想去** 按钮，随时收藏/取消
- 顶栏 `❤️ 清单` 或右下角悬浮按钮打开清单弹窗：点条目直达攻略、可复制、可清空
- 收藏数据保存在本机浏览器（localStorage），换浏览器/清缓存会丢，建议定期用弹窗里的"复制清单"备份

## 5. 🗺️ 足迹地图与成就

- 顶栏 `🗺️ 足迹` 打开：**34 省瓦片地图**（按地理排布）
- **点击瓦片**点亮/取消去过的省份；**想去的目的地自动显示为虚线框**
- 实时统计：已点亮 N/34 · 覆盖百分比 · 想去数 · 成就数
- **6 枚成就**：初出茅庐(1省) → 小有阅历(5省) → 山河过半(17省) → 区域制霸(八大区各1省) → 种草大师(收藏10个) → 全国大满贯(34省)
- 解锁瞬间弹 🏆 提示；`⧉ 复制旅行报告` 可生成文字版发朋友圈

## 6. 🧳 智能出行清单

- 进入任意省份详情页 → 点 `🧳 出行清单`
- 清单按该省**标签与季节**自动生成：通用证件杂物 + 海滨/雪山/沙漠/温泉/演出/边境/摄影/亲子/高反提示等专属分组 + 按最佳季节的提醒
- **勾选状态按省份保存在本机**，下次打开还在
- `⧉ 复制清单` 生成 `[x]/[ ]` 格式的纯文本，可粘贴到任何备忘录

## 7. 其他好用的小功能

- **🎲 随机**：选择困难症救星，随机抽一个省直接打开
- **出行月历**：每月 2-4 个当季最优目的地，9 月看喀纳斯、10 月看胡杨、12 月看冰雪
- **深色模式**：🌙 一键切换，选择会记住
- **⧉ 复制本省攻略**（详情页）：把该省精华整理成纯文本，粘贴到微信/备忘录即可分享
- **Ctrl+P 打印/存 PDF**（详情页）：自动展开全部城市、隐藏界面元素，变成一份纸质攻略
- **快捷键汇总**：`/` 聚焦搜索 · `Esc` 关闭弹窗 · `←`/`→` 在详情页翻省

## 8. 数据与隐私

- 你的足迹、收藏、清单勾选**只存在本机浏览器的 localStorage**，不上传任何服务器
- 清除浏览器数据会一并清除这些记录，请善用"复制"功能做备份
- 在线版与离线版数据互不相通（浏览器按网址隔离存储）

## 9. 常见问题

| 问题 | 解答 |
|---|---|
| 内容会过期吗？ | 数据为 2026 年 9 月整理，票价/开放时间以官方当日公告为准；仓库会持续更新 |
| 收藏丢了？ | 检查是否换了浏览器/设备，或清除了浏览器数据 |
| 能离线用吗？ | 下载离线版 HTML 即可；在线版需联网（首次加载约 700KB） |
| 想要某省更细的内容？ | 提 Issue 或按 docs/04 自行补充内容 |
