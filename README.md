# 🧭 中国旅行宝典 2026

一个**单文件、零依赖、离线可用**的交互式中国旅行攻略库：覆盖 34 个省级地区 · 243 座城市 · 802 个区县/板块 · 4572 条吃住玩条目，含美食榜、景点榜、特色体验、路线推荐、避坑指南、2023-2026 最新动态（新高铁/新景区/新热点），以及足迹地图、成就徽章、智能出行清单等互动功能。

## 📦 三个版本（按需选用）

| 版本 | 入口 | 适合场景 |
|---|---|---|
| 🌐 **在线版** | **https://wangzhaolong616-byte.github.io/travel-guide-2026/** | 手机/电脑浏览器直接打开，始终是最新版 |
| 💾 **离线版** | [中国旅行宝典2026.html](./中国旅行宝典2026.html) | 下载后双击即用，无网也能看（内容与在线版完全相同） |
| 📚 **全套源码** | 本仓库全部文件 | 想改内容、加功能、自己部署 |

> 💡 离线版也可以直接把 `中国旅行宝典2026.html` 拷贝到手机/平板/WPS 云盘，任何现代浏览器都能打开。

## ✨ 功能速览

- **三级攻略**：省 → 城市 → 区县/板块，点开即达
- **搜索**：支持城市、菜名、景点名、拼音（如 `sichuan`），按 `/` 快速聚焦
- **筛选**：八大地理区 + 主题标签（美食/海滨/古镇/雪山/避暑…）
- **🗺️ 足迹地图**：点亮去过的省份，想去自动虚线标记，6 枚成就徽章，一键复制旅行报告
- **🧳 智能出行清单**：按省份标签与季节自动生成，勾选进度本地保存
- **出行月历**：12 个月"这个月去哪"，自动定位当前月
- **❤️ 想去清单**：收藏目的地、一键复制分享
- **🎲 随机目的地**、深色模式、`←/→` 键盘翻省、Ctrl+P 打印/存 PDF

## 🚀 快速开始

**只是想用** → 打开 [在线版](https://wangzhaolong616-byte.github.io/travel-guide-2026/)，或下载 [离线版](./中国旅行宝典2026.html) 双击。
